The official Homebrew tap for `sylphx`, the [Sylphx](https://sylphx.com) command-line tool, and the AnyAgents, anymd, repomap and lockdocs tools.

The formula packages the `sylphx` binaries published on
[SylphxAI/sylphx-clients releases](https://github.com/SylphxAI/sylphx-clients/releases).

## Install

```bash
brew install sylphxai/tap/sylphx
brew install sylphxai/tap/anymd
brew install sylphxai/tap/repomap
brew install sylphxai/tap/lockdocs
brew install sylphxai/tap/anyagents
```

If Homebrew reports this tap as untrusted, run `brew trust --tap sylphxai/tap` and repeat the install command.

Upgrade:

```bash
brew update
brew upgrade sylphx
```

## Other install channels

| Channel | Command |
| --- | --- |
| **Homebrew (this tap)** | `brew install sylphxai/tap/sylphx` |
| **Install script** | `curl -fsSL https://github.com/SylphxAI/sylphx-clients/releases/latest/download/install.sh \| sh` |
| **crates.io** | `cargo install sylphx-cli` |
| **npm adapter** | `npm i -g @sylphx/cli` |

A binary installed with the install script updates itself with `sylphx update`;
a Homebrew, cargo or npm install updates through that package manager.

## Formula source

`Formula/sylphx.rb` is generated by `scripts/brew-formula.sh` in
SylphxAI/sylphx-clients. When a release is promoted to `latest`, the release
workflow opens a pull request here with the new version and checksums, and
auto-merge lands it through the merge queue once `ci-ok` passes (`brew style`,
`brew audit --strict --online`, install and `brew test` on Linux and macOS).
Change the formula by changing that script, not by editing this file.

The AnyAgents, anymd, repomap and lockdocs formulas use their existing GitHub release archives and SHA-256 digests, rendered with `SylphxAI/mcp-kit/scripts/package-managers.mjs`. AnyAgents on Linux requires glibc 2.34 or newer and kernel 5.9 or newer.
